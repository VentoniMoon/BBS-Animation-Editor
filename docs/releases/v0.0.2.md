# BBS Animation Editor 0.0.2

**Milestone:** ANCHORS 1.0 + the current Physics 3.0 / XPBD skirt prototype + latest editor/renderer improvements.

**Minecraft:** 1.12.2 · **Forge:** 14.23.5.2860 · **Java:** 8 (class version ≤52)

**Distributable:** `bbs-animation-editor-0.0.2.jar` — Forge-reobfuscated installation JAR, **not** a development `-dev` JAR.

## Included in the release

### CHARACTER → ANCHORS 1.0

- Take an object represented by a separate actor or a supported BODY PART and attach it to a character bone at a timeline key.
- The item becomes an actual editable, persistent BODY PART in the recipient's editor (Morph, position, rotation, scale, supported bone animation).
- Transfer a held item between actors with a world-preserving transform.
- **PLACE / RELEASE IN WORLD:** leave an item in exactly its saved world position, orientation, scale and visible Morph, independent of the holder's future movements.
- Pick up a placed object again; repeat pickup / placement / handoff.
- Scrub backward and forward through ownership changes without deleting source Records or duplicating the source object.
- Preserve the *rendered, edited* internal BODY PART pose at release/handoff rather than restoring the old unposed Morph. Snapshot stays in editor.dat using the `BakedPose` key.
- Previously saved anchor keys and body-part data retain legacy compatibility.

### Physics: new skirt functionality **included**

- Physics 3.0 connected 60-node XPBD Chameleon skirt simulation, source-skin topology, surface render and optional native-volume textured render.
- The cloth solver is independent of the older per-bone Jolt skirt rig; avoid enabling two conflicting skirt solvers.
- Jolt JNI **6.0.0** Java 8 bindings and native libraries for **Windows x86-64** and **Linux x86-64** are bundled inside the Forge mod JAR. Jolt native hair/body preview and its existing diagnostics are retained; no separate experimental Jolt mod should be placed in `mods/`.
- Previously implemented body-part physics, Jolt ragdoll, collision and Chameleon Weld code remain included.

**XPBD preview remains explicitly opt-in** so an existing scene using the old skirt solver is not silently changed. Add the following **JVM argument** to the Minecraft launcher:

```text
-Dbbs.editor.physics.skirt.xpbd=true
```

For the experimental alternate complete textured volume-skin draw, also add:

```text
-Dbbs.editor.physics.skirt.xpbdVolumeSkin=true
```

For optional Jolt hair/body preview, use:

```text
-Dbbs.editor.physics.jolt.preview=true
```

These are JVM/system properties, **not** chat commands and not Gradle `-P` flags when launching a packaged mod. Cloth visual topology and real leg collisions depend on the source Chameleon model and collider availability. The current solver is experimental; do not assume every custom skirt has full leg-contact support.

### Other retained systems

Existing CAMERA clips, camera modifiers, BetterLights, shader support, mirrors, multi-actor preview, 2K/4K export paths, Body Parts/POSE editing, lip sync, Russian localization and UI/theme preferences are retained from the frozen `main` snapshot.

## Installation

1. Use **Minecraft 1.12.2 / Forge 14.23.5.2860 / Java 8**.
2. Install the project's required matching McHorse dependencies (Blockbuster 2.7.1, McLib 2.4.3, compatible Metamorph; optional Emoticons/Chameleon/BetterLights for their respective features).
3. Copy **`bbs-animation-editor-0.0.2.jar`** into `.minecraft/mods/`. Remove an older `bbs-animation-editor-*.jar` before launching to avoid loading duplicate mod IDs.
4. To test the skirt XPBD visual preview, add `-Dbbs.editor.physics.skirt.xpbd=true` as a JVM argument in the Minecraft launcher.
5. Existing scenes and Records should be backed up before opening in a new editor build. Older ANCHORS release/handoff keys authored before the posed-Morph fix must be removed and recreated to capture current internal-bone edits.

## Release validation

GitHub Actions builds the release in **Java 8** using ForgeGradle's `jar` + `reobfJar`, with `-PciDependencies -PenableJoltExperimental`, and checks:
- the mod ID, metadata version **0.0.2**, Forge core plugin manifest and ZIP integrity;
- the presence of connected XPBD runtime/solver, two skirt renderers and new ANCHORS classes;
- the bundled Windows and Linux native Jolt libraries;
- Java 8-compatible classfile versions;
- a SHA-256 checksum shipped next to the JAR.

**Freeze:** `v0.0.2` Git tag points to the exact source commit that produced the verified release asset. This pre-release milestone documents the tested feature state, not a claim that all experimental native renderer/physics variants are complete.
