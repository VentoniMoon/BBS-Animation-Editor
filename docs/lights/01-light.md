# LIGHT — основной источник освещения

> BBS Animation Editor · Blockbuster 2.7.1 · BetterLights 1.0.3.PREVIEW · Minecraft 1.12.2

## Назначение

Группа **LIGHT** задаёт собственно источник света: включён ли он, какого он цвета, насколько сильный, как далеко действует и какую область освещает. Обычный свет воздействует на поверхности объектов. Тени, блик в объективе и видимое рассеяние в воздухе настраиваются отдельно.

Путь в редакторе: **CAMERA → LIGHTS → выбрать источник → LIGHT → LIGHT**. Для записанного актёра-света: **POSE → выбрать актёра BetterLights → LIGHT → LIGHT**.

В CAMERA переключатель **Enabled** в секции SOURCE выключает *сценовый объект целиком*, тогда как **LIGHT → Enabled** управляет нативным свойством освещения самого источника. Это два разных уровня настроек.

## Поля

| Функция | Что делает | Как использовать |
|---|---|---|
| **Enabled** | Включает/отключает вклад источника в освещение, не удаляя сам объект и остальные сохранённые параметры. | Снимите галочку для сравнения сцены до/после установки света. |
| **Color** | Цвет излучения в формате RGB; при доступности нативного значения учитывается и альфа. | Тёплый оранжевый для ламп, холодный голубой для лунного света, насыщенные цвета для неона. |
| **Intensity** | Сила/яркость излучения. В оригинальном меню для этого есть ползунок. | Увеличивайте постепенно: очень большие значения могут пересветить поверхность. |
| **Distance** | Дальность влияния света. Увеличение обычно расширяет освещаемую область. | Делайте её не больше необходимого для конкретного кадра. |
| **InnerAngle** | Внутренний угол конуса, внутри которого свет наиболее равномерный/интенсивный. | Меньший угол создаёт направленный пучок. |
| **OuterAngle** | Внешний угол конуса: граница действия прожектора и область перехода интенсивности. | При большем значении свет охватывает более широкую сцену. Обычно держите его не меньше InnerAngle. |
| **DirectionX / DirectionY / DirectionZ** | Компоненты направления в оригинальном BetterLights. | **В BBS Animation Editor их заменяет линия Origin → Target.** Эти нативные значения сохранены в данных, но скрыты в панели, поскольку движок во время рендера рассчитывает направление из мировых точек. |
| **Position** | Положение источника в исходной конфигурации BetterLights. | Здесь управляется не через отдельное нативное поле, а через **Origin** — координаты и 3D-гизмо. |

**Про числовые пределы:** редактор читает точные минимальные и максимальные значения из `GenericNumberValue` установленной версии BetterLights. Они могут различаться между сборками; ориентируйтесь на пределы ползунка, а не на условные универсальные числа.

## Как работать с размещением

1. В CAMERA нажмите **+ ADD**: источник создастся перед текущей камерой.
2. Перейдите в **ORIGIN** и переместите точку начала света трёхмерным гизмо.
3. Перейдите в **TARGET** и направьте прожектор на объект. Точка Target независима: движение Origin само по себе не перемещает Target.
4. В **LIGHT** установите `Enabled`, `Color`, `Intensity`, `Distance`, затем `InnerAngle`/`OuterAngle`.
5. Только после этого подключайте Shadows, Flare и Fog: так легче понять вклад каждого эффекта.

## Управление

- **Ползунок:** щелчок или перетаскивание в пределах заданного BetterLights диапазона.
- **Точное число:** щёлкните по числовому полю, введите значение и подтвердите Enter.
- **Цвет:** щёлкните по цветному образцу, выберите тон, насыщенность, яркость и непрозрачность; для точного значения используйте поле `#AARRGGBB`.
- **Включение:** переключатель ON/OFF.
- **Прокрутка:** колесо мыши по списку параметров только текущего раздела.

В CAMERA настройки источника сохраняются в данных сцены, без ключей. В POSE они принадлежат базовому morph актёра либо **выбранному Origin-ключу**. Для анимированного света меняйте именно значения нужного ключа.

## Частые ошибки

- Свет не виден: проверьте включение сцены, `LIGHT.Enabled`, расстояние, интенсивность и направление Target.
- Пучок слишком широкий: уменьшите OuterAngle.
- Не видно луча в воздухе: обычная группа LIGHT не создаёт объёмный свет — включите **Volumetric Fog Effect**.
- Не видно теней: проверьте **Shadows**, настройки шейдера и поддерживаемый BetterLights рендер.
