# SHADOWS — тени от источника BetterLights

> BBS Animation Editor · руководство к нативным значениям BetterLightsMorph

## Назначение

Раздел **SHADOWS** управляет затенением объектов относительно выбранного источника. Это не то же самое, что обычный свет: при выключенных тенях источник может продолжать освещать поверхность.

Путь: **CAMERA → LIGHTS → LIGHT → SHADOWS**. Для актёра — вкладка **LIGHT** в POSE и затем **SHADOWS**.

## Параметры на исходных снимках

| Параметр | Назначение | Практический совет |
|---|---|---|
| **Enabled** | Разрешает источнику рассчитывать собственные тени. | Включайте там, где тени принципиальны для кадра; это отдельная нагрузка на рендер. |
| **Fov offset** | Смещение угла охвата пространства, используемого для построения теней. Изменяет область их расчёта, но не положение самого Origin. | Если тень пропадает близко к краю светового конуса, попробуйте осторожно увеличить охват. |
| **Distance** | Дальность области, в которой от источника рассчитываются тени. Может не совпадать с основным Light.Distance. | Не задавайте дальность теней значительно больше нужной сцены. |
| **Дополнительный переключатель** | В оригинальном разделе виден отдельный флажок, но его подпись на предоставленном фрагменте обрезана. | Не приписываем ему назначение без названия и проверки версии BetterLights; в редакторе он появится автоматически под своим нативным именем. |
| **Size offset** | Поправка к размеру области тени/её проекции. | Изменяйте небольшими шагами; если контур тени смещается или обрезается, вернитесь к нейтральному значению. |
| **Falloff distance** | Расстояние, на котором происходит спад/ослабление теневого эффекта. | Полезно для плавного исчезновения далёких теней. |
| **Start angle** | Начало углового интервала затенения. | Вместе с End angle ограничивает область эффекта; точная ориентация зависит от BetterLights. |
| **End angle** | Конец углового интервала затенения. | Проверьте в предпросмотре, какая часть конуса попадает в заданный диапазон. |
| **Angle factor offset** | Дополнительная поправка углового коэффициента/затенения. | Тонкая настройка: начните с значения по умолчанию и меняйте после основных углов. |

В оригинальном меню были видны числовые шкалы для ряда параметров (например, Fov offset со знаком, а также Start/End angle). **Полные точные диапазоны не фиксируются в мануале**, потому что Blockbuster строит их из аннотаций `ConfigProperty(min,max)` именно установленного BetterLights. Новый инспектор получает те же границы от нативного `ValueSerializer`.

## Порядок настройки

1. Сначала настройте LIGHT: направление, Distance, Intensity и углы.
2. В SHADOWS включите Enabled и проверьте наличие тени у объекта.
3. Подберите Shadows.Distance, чтобы далёкие тени не расходовались на невидимую часть сцены.
4. При обрезании теней по краям попробуйте Fov offset.
5. После этого меняйте Size offset и Falloff distance.
6. Start angle, End angle и Angle factor offset используйте только для тонкой доводки после проверки эффекта в движении камеры.

## Проблемы и производительность

- **Нет теней:** недостаточно только переключателя — необходим поддерживаемый режим BetterLights/шейдеров и подходящие объекты.
- **Рваные края:** могут зависеть от разрешения карты теней и шейдеров, а не только от параметров панели.
- **Тени исчезают при повороте камеры:** сначала проверьте Fov offset и Distance, затем совместимость рендера с OptiFine.
- **Просадки FPS:** теневые источники обычно дороже обычных. При многосветовой сцене оставьте тени только на ключевых источниках.

Не путайте **Shadows.Distance** (дальность теней) и **LIGHT.Distance** (дальность основного освещения).
