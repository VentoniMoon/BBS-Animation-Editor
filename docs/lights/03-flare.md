# FLARE EFFECT — блик источника в камере

> BBS Animation Editor · нативный эффект BetterLightsMorph

## Назначение

**Flare Effect** — это видимый камерой блик/свечение, связанное с источником. Он нужен для экранных эффектов ярких ламп, фонарей, прожекторов, солнечных бликов или неоновых источников.

Этот эффект **не заменяет реального освещения** и **не создаёт тени**. В отличие от LIGHT.Intensity, параметры блика описывают визуальный эффект при взгляде камерой.

Путь: **CAMERA → LIGHTS → LIGHT → FLARE** либо **POSE → LIGHT → FLARE**.

## Настройки

| Параметр | Что он делает |
|---|---|
| **Enabled** | Включает или отключает видимый Flare Effect независимо от основного источника и Shadows. |
| **Color** | Цвет блика; в исходном редакторе выбирается в раскрывающейся палитре с тоном, насыщенностью и яркостью. В новом инспекторе дополнительно доступен alpha-канал и точный ARGB-код. |
| **Дополнительные нативные параметры установленной сборки** | Их список автоматически читается из дерева `Flare Effect.*` самого BetterLights. Это позволяет сохранить параметры конкретной версии без выдуманных замен. На приложенном фрагменте остальные названия Flare не видны — их назначение нельзя достоверно восстановить только по снимку палитры. |

### Работа с палитрой

1. Включите Flare Effect.Enabled.
2. Нажмите на цветной образец. Большой квадрат выбирает насыщенность/яркость; вертикальная полоса справа — цветовой тон.
3. Отрегулируйте Alpha: непрозрачность эффекта, **если** конкретный нативный параметр BetterLights учитывает прозрачность.
4. Для точного цвета используйте шестнадцатеричный код `#AARRGGBB`: `AA` — альфа, `RR` — красный, `GG` — зелёный, `BB` — синий.

## Рекомендации для кинематографической сцены

- Для неонового казино используйте цвет блика, близкий к цвету самого LIGHT.
- Не включайте яркие блики на всех источниках: иначе изображение будет визуально перегружено.
- Проверяйте эффект **с камеры финального кадра** — результат зависит от её положения и взгляда.
- Делайте финальный тест в экспорте видео: шейдерные и постэффектные элементы могут зависеть от конфигурации BetterLights/OptiFine и режима захвата.

Если Flare Effect.Enabled включён, но блика нет, убедитесь, что источник попадает в кадр и эффект поддерживается используемым рендер-пайплайном. Не пытайтесь компенсировать отсутствие эффекта экстремальной LIGHT.Intensity.
